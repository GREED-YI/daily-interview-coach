# 05. 사용자 흐름

[04 기능 명세](04-feature-spec.md)의 규칙을 사용자가 움직이는 순서로 그린다. 5단계 와이어프레임은 이 흐름의 화면들을 그린다. 다이어그램은 GitHub에서 그림으로 보인다.

## 1. 처음 온 사람

검색이나 공유 링크로 들어와서, 가입 전에 한 문제를 풀어보고, 가입과 온보딩을 거쳐 홈에 도착한다.

```mermaid
flowchart TD
  A(["유입: 검색, 공유 링크, 소개"]) --> B{"공유 링크로 왔나?"}
  B -- 예 --> C["공유 페이지: 카드 + 나도 풀어보기"]
  B -- 아니오 --> D["랜딩"]
  C --> S["분야 하나 고르기: 공통 CS · 백엔드 · 프론트엔드"]
  D -- 한 문제 풀어보기 --> S
  S --> E["체험: 샘플 질문 → 채점 → 꼬리질문 1개"]
  D -- 로그인 --> G["로그인: GitHub · Google · 카카오"]
  E --> F["체험 결과 + 가입 권유"]
  S -. 오늘 체험 횟수 초과 .-> M["내일 다시 + 가입 권유"]
  F -- 가입하기 --> G
  F -- 나중에 --> D
  G --> H{"처음 로그인?"}
  H -- 예 --> I["온보딩 ① 동의"] --> J["② 연습 범위 · 체험한 분야 미리 선택"] --> K["③ 알림 · 건너뛰기 가능"] --> T{"오늘 같은 브라우저에서 체험했나?"}
  T -- 예 --> V["체험을 첫 기록으로 · 스트릭 1일"] --> L["홈"]
  T -- 아니오 --> L
  H -- 아니오 --> L
```

## 2. 매일 연습

알림이나 직접 접속으로 들어와 오늘의 질문 세션을 하고, 결과를 본 뒤 끝난다.

```mermaid
flowchart TD
  A(["사용자가 정한 알림 시각"]) --> B{"오늘 이미 풀었나?"}
  B -- 예 --> Z(["알림 안 보냄"])
  B -- 아니오 --> C["웹 푸시: 오늘의 질문이 도착했어요 / 복습할 질문이 있어요"]
  C -- 클릭 --> D{"로그인 상태?"}
  D -- 아니오 --> E["로그인"] --> F
  D -- 예 --> F["홈"]
  U(["직접 접속"]) --> F
  F --> G{"오늘의 질문 상태"}
  G -- 아직 안 풂 --> H["세션 시작"]
  G -- 하던 중 --> I["이어하기"]
  G -- 끝냄 --> J["오늘 완료 화면"]
  H --> K["세션 · 3번 흐름"]
  I --> K
  K --> L["종합 결과"]
  L -- 공유 --> M["공유 카드 만들기"]
  L --> J
```

### 홈 화면의 세 가지 상태

| 상태 | 보이는 것 |
|---|---|
| 아직 안 풂 | 오늘의 질문 카드(복습이면 "복습"), 시작 버튼, 스트릭 |
| 하던 중 | "이어서 하기"와 진행 단계(예: 꼬리질문 2/3) |
| 끝냄 | 오늘의 점수, 스트릭, 다음 복습 예정, 기록·리포트·북마크 바로가기, "내일 또 만나요" |

## 3. 세션 (본 질문 + 꼬리질문)

```mermaid
flowchart TD
  A["본 질문"] --> B["답변 작성"]
  B -- 모르겠어요 --> Q["모범 답안 + 참고 자료 · AI 채점 없음, 0점, 복습 1칸"] --> L
  B --> C{"30자 이상, 2,000자 이하?"}
  C -- 아니오 --> B
  C -- 예 --> E["AI 채점 · 결과가 흘러나오듯 표시"]
  E -- 실패 또는 15초 초과 --> F["다시 채점하기 · 답변 유지"] --> E
  E --> G["채점 결과: 점수, 잘한 점, 빠진 점, 모범 답안, 참고 자료, 👍/👎"]
  G --> H{"꼬리질문을 더 할까? · 2개까지는 항상, 최대 3개"}
  H -- 예 --> I["꼬리질문"] --> J["답변"] --> K["짧은 채점"] --> H
  I -- 모르겠어요 --> P["꼬리질문 기대 답안"] --> L
  H -- 아니오 --> L["종합 결과: 점수, 꼬리질문별 결과, 다음 복습일"]
  L --> N["복습 상자 갱신"]
```

- 사용 상한은 세션 **안에서** 확인하지 않는다. 오늘의 질문 세션은 항상 보장되고, 프로젝트 질문 세션은 시작하기 전에 확인한다(5번 흐름). 시작한 세션은 끝까지 할 수 있다.
- 세션은 **단계마다 저장**된다. 어느 단계에서 나가도 다시 들어오면 멈춘 곳부터 이어진다. 날짜가 바뀌어도 이어갈 수 있다.
- 채점 결과와 꼬리질문 화면에서 질문을 북마크할 수 있다.

## 4. 오늘의 질문 고르기

사용자에게 보이지 않는 흐름이다. 그날 처음 필요할 때(알림을 보낼 때나 첫 접속) 한 번 고르고 자정까지 고정한다.

```mermaid
flowchart TD
  A(["그날 처음 필요할 때: 알림 발송 또는 첫 접속"]) --> B{"복습일이 된 질문이 있나?"}
  B -- 예 --> C["가장 오래 밀린 복습 질문"]
  B -- 아니오 --> D{"범위 안에 안 푼 질문이 있나?"}
  D -- 예 --> E["새 질문 · 최근 나온 주제는 피함"]
  D -- 아니오 --> F["가장 가까운 복습 질문을 앞당김 + 범위 넓히기 안내"]
  C --> G["오늘의 질문으로 고정 · 한국 시간 자정까지"]
  E --> G
  F --> G
```

내 프로젝트 질문도 부족했으면 복습 상자에 들어가므로, 복습일이 되면 이 흐름으로 오늘의 질문이 될 수 있다.

## 5. 내 프로젝트 기반 질문

```mermaid
flowchart TD
  A["내 프로젝트 목록"] -- 새로 등록 --> B{"등록한 프로젝트가 3개 미만?"}
  B -- 아니오 --> C["하나를 지워야 등록할 수 있다고 안내"]
  B -- 예 --> E{"오늘 사용 한도가 남았나?"}
  E -- 아니오 --> X["오늘은 사용 한도를 모두 썼어요. 내일 다시 만나요"]
  E -- 예 --> D["이름 + README·설명 붙여넣기 · 최대 10,000자"]
  D --> F["질문 5개 생성"]
  F -- 실패 --> R["다시 생성하기 · 입력 유지"] --> F
  F --> H["프로젝트 질문 목록"]
  H -- 질문 고르기 --> T{"오늘 사용 한도가 남았나?"}
  T -- 아니오 --> X
  T -- 예 --> I["세션 · 3번 흐름"]
  A -- 삭제 --> L{"확인 창: 질문, 기록, 복습 일정도 함께 지워져요"}
  L -- 확인 --> M["삭제"]
  L -- 취소 --> A
```

## 6. 탈퇴

```mermaid
flowchart TD
  A["설정 → 탈퇴"] --> B["지워지는 데이터 목록 안내"]
  B --> C["탈퇴합니다 입력 · 똑같이 입력해야 버튼이 켜짐"]
  C --> D{"마지막 로그인이 24시간 이내?"}
  D -- 아니오 --> E["같은 소셜 로그인으로 다시 확인"]
  E -- 성공 --> F
  E -- 실패 또는 취소 --> A
  D -- 예 --> F["즉시 삭제 + 로그아웃"]
  F --> G["랜딩"]
```

## 7. 예외 상황

| 상황 | 흐름 |
|---|---|
| 로그인이 필요한 화면에 로그인 없이 들어옴 | 로그인 → 원래 가려던 화면으로 돌아감 |
| 온보딩을 마치지 않고 나갔다 들어옴 | 온보딩의 멈춘 단계부터 |
| 알림 권한을 거부함 | 홈에 "알림을 켜면 매일 질문을 받아요" 배너. 브라우저 설정에서 켜는 방법 안내 |
| 아이폰에서 홈 화면에 추가하지 않고 알림을 켜려 함 | 홈 화면 추가 방법 안내 |
| 체험 횟수 초과 | 내일 다시 + 가입 권유 |
| 채점·질문 생성 실패 | 입력을 지우지 않고 다시 시도 버튼 |
| 오늘 사용 한도를 다 씀 (내 프로젝트) | 시작 버튼 대신 "오늘은 사용 한도를 모두 썼어요. 내일 다시 만나요". 오늘의 질문은 계속 풀 수 있다 |
| 서비스 월 예산 소진 | 모든 AI 기능의 시작 전에 같은 안내. 이미 시작한 세션은 끝까지 |
| 탈퇴한 사용자의 공유 링크 | 카드 대신 랜딩으로 |
