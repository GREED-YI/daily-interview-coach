## 가장 가까운 경쟁 서비스

- **매일메일**: "매일 아침 질문 1개" 습관을 만든 원조다. 질문과 답만 보내고 채점이나 꼬리질문은 없었다. **2026-04-17에 종료**됐고, 지금 도메인은 운영진과 무관한 제3자 소유라고 안내돼 있다. 봄봄이 앱 푸시로 이어가고 있지만 AI 채점은 없다. → **TailQ가 노릴 빈자리.**
- **꼬꼬면**: 개발자 전용 AI 모의면접. 꼬리질문, 오답노트, 랭커 답변 비교까지 있다. 매일 질문과 습관 장치는 없고, 유료 토큰제다.
- **테크톡**: 무료, AI 채팅 면접, 꼬리질문, 오답노트로 TailQ의 흐름과 가장 비슷하다. iOS 전용이고 매일 질문과 점수는 없다.
- **Greenroom**: GitHub 레포를 읽고 내 프로젝트에 대해 묻는 기능을 이미 상용으로 한다. 영어 음성이고, 레포 분석은 유료 플랜이다.

## TailQ의 차별점

1. **한국어·무료로 "매일 질문 → 채점 → 꼬리질문 → 간격 반복"을 한 흐름에 묶는다.** 매일메일이 닫힌 뒤 이 자리가 비어 있다.
2. **내 프로젝트 질문을 매일 반복과 결합한다.** 아이디어 자체는 새롭지 않지만, 한국어·무료·데일리로 정식 제공하는 곳은 찾지 못했다.
3. **비전공자·부트캠프 수강생을 위한 무료 서비스.** 경쟁 AI 면접 서비스는 대부분 회차권이나 토큰제다.

## 차별점이 아닌 것

| 항목 | 이유 | TailQ에 주는 의미 |
|---|---|---|
| 꼬리질문 | 꼬꼬면, 테크톡, 사람인, Greenroom이 이미 한다 | 이름(TailQ)은 꼬리질문이지만, **홍보는 "매일 + 채점 + 반복"의 조합**으로 한다 |
| 내 프로젝트 기반 질문 | Greenroom이 상용, 해커톤 프로젝트도 여럿 있다 | "최초"라고 말하지 않는다. 한국어·무료·데일리 결합으로 설명한다 |
| 복습·streak | 테크톡 오답노트, Greenroom streak | 기본기로 갖추되 차별점으로 내세우지 않는다 |
| 질문 콘텐츠 | 무료 GitHub 저장소와 [매일메일 공개 아카이브](https://github.com/maeil-mail/maeil-mail-contents)가 이미 있다 | 매일메일 아카이브는 **라이선스 표기가 없어 가져다 쓰지 않는다.** 질문은 직접 만든다 |
