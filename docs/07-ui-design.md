# 07. UI 디자인 방향

와이어프레임(#7)의 구조 위에 입히는 시각 기준이다. 색과 로고는 [06 브랜드](06-brand.md)를 따른다. Figma: [TailQ › 07 UI 디자인](https://www.figma.com/design/wPjTOU5FJdhdrMWOGZTHdh)

## 2026 트렌드에서 가져온 것과 버린 것

| 트렌드 | 판단 | 이유 |
|---|---|---|
| 차분한 UI (색·선·아이콘을 줄여 덜 시끄럽게) | **적용** | "시크하고 절제된" 방향과 같다 ([Linear 2026 리프레시](https://linear.app/now/behind-the-latest-design-refresh)) |
| 접근성을 처음부터 넣은 색 체계 | **적용** | 다크 모드까지 지원하므로 필수다 |
| 목적이 있는 모션 | **적용** | 기다림과 성취의 순간에만 움직인다 |
| 큰 글자 히어로 | **적용** | 랜딩 3초 규칙에 가장 효과가 크다 |
| AI 응답 스켈레톤·스트리밍 표시 | **적용** | 채점을 기다리는 화면에 쓴다 |
| 벤토 그리드 | **부분 적용** | 랜딩의 기능 소개 구역에만. 앱 화면까지 벤토로 채우면 산만하다 |
| 글래스모피즘(반투명 유리) | **랜딩에 적용, 앱은 하단 탭·모달 배경만** | 랜딩은 첫인상이 목적이라 화려해도 된다. 매일 읽고 쓰는 앱 화면은 대비가 떨어지면 안 되므로 글자는 항상 불투명한 면 위에 둔다 |
| 3D 모션 | **랜딩 첫 화면에만** | 3D 여우 꼬리 Q가 마우스·스크롤에 따라 천천히 회전한다. 처음 화면이 뜬 뒤 불러오고, 성능이 낮은 기기나 "동작 줄이기"에서는 정지 이미지로 대신한다 |
| 클레이·브루탈리즘 | **안 함** | 귀엽거나 거칠어서 신뢰가 중요한 채점 서비스와 맞지 않는다 |

처음엔 글래스모피즘과 3D를 모두 "안 함"으로 정했으나, 첫인상을 강하게 주고 싶다는 의견에 따라 **랜딩은 화려하게, 앱은 차분하게**로 바꿨다 (2026-10-22).

## 기초 값

| 항목 | 값 |
|---|---|
| 글꼴 | 서비스는 **Pretendard**, Figma는 대신 Noto Sans KR (Figma에서 Pretendard를 쓸 수 없어서. 생김새와 크기가 거의 같다) |
| 글자 크기 | 랜딩 제목 40(PC 56) · 화면 제목 24 · 섹션 제목 18 · 본문 16(줄 높이 160%) · 보조 14 · 캡션 13 · 최소 12. 점수 숫자는 고정폭 숫자 |
| 줄바꿈 | 한글은 어절 단위로 끊는다 (`word-break: keep-all`) |
| 모서리 | 카드 16 · 버튼·입력칸 12 · 칩 8 · 잔디 칸 3 |
| 간격 | 4의 배수: 4 · 8 · 12 · 16 · 24 · 32 · 48 · 64. 모바일 좌우 여백 20 |
| 카드 | 그림자 대신 **면색**(라이트 `#F6F7F8`, 다크 `#171A1F`). 입력·선택 카드만 1px 선. 그림자는 바텀시트와 모달에만. 카드 안에 카드를 넣지 않는다 |
| 아이콘 | 1.5px 선, 24px 격자, 둥근 끝 (Lucide 계열). 채운 아이콘은 선택된 탭에만 |
| 강조색 | 화면마다 가장 중요한 버튼 하나에만 |

## 서비스 고유 요소

| 요소 | 모양 |
|---|---|
| **꼬리잇기** | 불꽃 대신 **여우 꼬리 아이콘 + "꼬리잇기 12일째"**. 로고의 여우 꼬리에서 따온 아이콘이다 |
| **학습 잔디** | GitHub처럼 칸. 5단계 색 (라이트 `#EEF0F2 → #C3E9DA → #7DD3B4 → #2FA884 → #0E7C66`, 다크 `#1C2026 → #173D33 → #1F6B55 → #2A9E7C → #34C79A`). 휴식권 쓴 날은 빗금 칸. 단계 사이 대비가 낮아서 칸마다 날짜·점수 툴팁과 합계 숫자를 같이 보여준다 |
| **점수** | 큰 숫자 + 얇은 링 하나. 잘한 점은 강조색, 보완할 점은 주황. 빨강·초록 이분법은 쓰지 않는다 |
| **숙련도** | 점 5개(●●○○○), 채운 점은 강조색 |
| **채점 대기** | 스피너 대신 결과 자리에 스켈레톤과 "채점하고 있어요" |

## 모션

- 길이 150~250ms, 가속 곡선 `cubic-bezier(0.2, 0, 0, 1)`
- **움직이는 곳**: 채점 대기 스켈레톤, 점수가 0에서 올라가는 카운트(0.6초 한 번), 꼬리잇기 +1, 꼬리질문이 차례로 나타나기, 오늘 잔디 칸이 채워지기, 랜딩 기능 카드 등장
- **움직이지 않는 곳**: 탭 전환, 목록, 본문 스크롤, 패럴랙스
- 사용자가 기기에서 "동작 줄이기"를 켜면 모두 끈다

## PC 레이아웃 (모든 화면)

| 너비 | 구조 |
|---|---|
| 모바일 (~767px) | 하단 탭 5개, 한 열 |
| 태블릿 (768~1023px) | 하단 탭, 내용 최대 너비 640 가운데 |
| PC (1024px~) | **왼쪽 사이드 메뉴**(홈·복습·기록·프로젝트·MY)로 바꾼다. 세션·문서처럼 읽고 쓰는 화면은 내용 최대 720 가운데, 홈·기록·리포트처럼 훑어보는 화면은 2열 |

- 랜딩은 PC에서 첫 화면 좌우 분할(왼쪽 제목·버튼, 오른쪽 채점 화면 목업)로 3초 규칙을 지킨다.
- 모달은 PC에서 가운데 480 너비, 토스트는 오른쪽 아래.

## 따라 할 참고

- 결과 화면: 토스 송금 완료처럼 큰 숫자 하나, 한 줄 문장, 다음 행동 하나
- 잔디: GitHub 기여 그래프와 [색약 테마](https://github.blog/changelog/2021-09-29-colorblind-themes-beta/)
- 꼬리잇기·휴식권: [Duolingo](https://blog.duolingo.com/how-duolingo-streak-builds-habit)의 원리(휴식권은 여유, 이정표 축하)만 가져오고 캐릭터와 죄책감 주는 알림은 빼기
- 목록·기록: Linear처럼 옅은 구분선과 낮춘 장식
